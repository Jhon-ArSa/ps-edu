🚀 CÓMO SUBIR AL HOSTING (3 OPCIONES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━ OPCIÓN 1: Script Automático (MÁS FÁCIL) ━━━

1. Sube el archivo al servidor:
   create-upload-directories.php

2. Accede desde el navegador:
   https://tu-dominio.com/create-upload-directories.php

3. El script crea todo automáticamente

4. Elimina el archivo después:
   create-upload-directories.php

━━━ OPCIÓN 2: cPanel File Manager ━━━

1. Entra a cPanel → File Manager

2. Sube TODA la carpeta del proyecto

3. Verifica que exista:
   public/uploads/ con todas las subcarpetas

4. Permisos (click derecho en uploads/):
   • Change Permissions
   • Valor: 755 o 775
   • Marcar: "Recurse into subdirectories"
   • Change Permissions

━━━ OPCIÓN 3: FTP (FileZilla) ━━━

1. Conecta por FTP a tu hosting

2. Sube toda la carpeta public/uploads/

3. Asegúrate de subir:
   ✓ .htaccess
   ✓ index.php
   ✓ Todas las subcarpetas

4. Permisos (click derecho):
   • File Permissions
   • Numeric: 755

⚠️  SI AÚN DA ERROR 404
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Verifica permisos de uploads/:
   Debe ser 755 o 775

2. Limpia caché del navegador:
   Ctrl + F5 o Cmd + Shift + R

3. Elimina caché de Laravel (si tienes SSH):
   php artisan config:clear
   php artisan cache:clear

4. Si NO tienes SSH:
   • Borra: bootstrap/cache/config.php
   • Borra: bootstrap/cache/routes-*.php

5. Verifica APP_URL en .env:
   APP_URL=https://tu-dominio-real.com
