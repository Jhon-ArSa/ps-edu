🎯 MÉTODO RECOMENDADO (MÁS FÁCIL):

1. Abre tu terminal en el directorio del proyecto

2. Ejecuta este comando:

   php artisan db:migrate-to-local

3. Sigue las instrucciones en pantalla

4. Limpia la caché:

   php artisan config:clear
   php artisan cache:clear

5. Verifica la conexión:

   php artisan db:show

6. Inicia el servidor:

   php artisan serve

7. Accede a: http://127.0.0.1:8000

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📚 OTROS MÉTODOS DISPONIBLES:

🔹 Método 2 - Script PowerShell (Windows):
   .\migrate-database.ps1

🔹 Método 3 - Script Bash (Linux/Mac):
   chmod +x migrate-database.sh
   ./migrate-database.sh

🔹 Método 4 - Laravel Export (sin mysqldump):
   php artisan db:export-laravel

🐛 PROBLEMAS COMUNES:

❌ "mysqldump: command not found"
   → Solución: php artisan db:export-laravel

❌ "Access denied for user 'root'"
   → Solución: Verifica password de MySQL (admin)

❌ "Can't connect to MySQL server"
   → Solución: Inicia MySQL local (XAMPP/WAMP/servicio)

❌ "Connection to AWS RDS failed"
   → Solución: Verifica tu conexión a internet
