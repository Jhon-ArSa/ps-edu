✅ PASO 1: CORREGIR SISTEMA DE ARCHIVOS (Soluciona Error 404)

1. Ver qué se migrará (sin hacer cambios):

   php artisan storage:fix --dry-run

2. Ejecutar la corrección:

   php artisan storage:fix

3. Crear symlink:

   php artisan storage:link

4. Limpiar caché:

   php artisan config:clear
   php artisan cache:clear

✅ PASO 2: PROBAR SISTEMA DE EMAILS

1. Probar configuración de email:

   php artisan mail:test

2. Si falla, seguir diagnóstico en pantalla

3. Alternativa (si puerto 587 no funciona):
   
   Editar .env:
   MAIL_PORT=465
   MAIL_ENCRYPTION=ssl
   
   Luego:
   php artisan config:clear
   php artisan mail:test

✅ PASO 3: VERIFICAR CORRECCIONES

1. Subir un material en un curso (como docente)
2. Verificar que el archivo se guarda
3. Verificar que NO sale error 404
4. Crear un usuario de prueba
5. Verificar que llega el email con credenciales

🐛 SOLUCIÓN DE PROBLEMAS:

┌─ Error 404 persiste después de migración ─────────────────────┐
│                                                                │
│ Solución:                                                      │
│ 1. Verificar que el symlink existe:                           │
│    ls -la public/storage                                       │
│                                                                │
│ 2. Si no existe o no es un symlink:                           │
│    rm -rf public/storage                                       │
│    php artisan storage:link                                    │
│                                                                │
│ 3. Limpiar caché del navegador (Ctrl+F5)                      │
└────────────────────────────────────────────────────────────────┘
